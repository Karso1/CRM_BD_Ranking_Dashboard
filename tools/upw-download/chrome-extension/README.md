# UPW 现有 Chrome 导出扩展

这是 Manifest V3 本地扩展源码，**0.3.7 更新后需重新加载；自动恢复已通过本地回归测试，尚未完成真实后台端到端验证**。点击扩展图标会在当前 UPW 页面显示可拖动、可收起的操作面板，不再弹出 Chrome 工具栏小窗。进入各导出页后先重置筛选，代理关系重新查询全量，按钮、表格和总数只从对应的可见标签页读取，避免继承日常查询的代理模式、UID 等筛选。交易日期填入后先用 Enter 提交日期控件，再点击查询；若仍返回其他日期，先在当前页面重新提交并查询一次。筛选栏 15 秒未完整加载、筛选或查询超时时，会自动刷新并恢复任务，每次任务最多刷新 3 次。刷新前保存已完成的卡片、代理关系和完整交易日期，恢复时跳过这些项目；未完成日期的部分分段可能重新导出。结果条数不变本身不会触发刷新，明确的零数据、校验失败和用户停止不会自动刷新。已有未导入的下载文件会保留。只允许在用户已登录的原有 Chrome 标签页运行；不打开独立浏览器，不读取或保存密码、Cookie、令牌。按后台页面现有筛选与导出按钮下载成功卡片全量、指定日期逐日已完成交易、从最新开始的代理关系分段。它生成含页面条数与 CSV 绝对路径的 JSON 清单供 `../import_exports.py` 校验。扩展不会直接修改网站、原始数据、测试环境或正式环境。

## 安装前需要你确认的权限

| 声明 | Chrome 授予的能力 | 本扩展的用途与边界 |
|---|---|---|
| `https://upayv3.alliancebxc.com:31007/*` | 读取和操作这个网站页面内容 | 在已登录页面选择状态、日期、分段，并点查询/导出。页面里若显示敏感信息，技术上也能读到；源码仅读取筛选、计数、首行和弹窗文字，不发送到其他网站。**不申请访问所有网站**。 |
| `downloads` | 查看浏览器下载记录（包含其他网站下载的文件名、路径、来源）及发起下载 | 找到本次 UPW 导出的 CSV 绝对路径，保存 JSON 清单。代码按 UPW 文件名前缀和开始时间匹配；此权限在 Chrome 层面比 UPW 更宽，无法进一步限定到一个站点。 |
| `storage` | 在 Chrome 本机保存扩展状态 | 保存进度与错误提示，关闭弹窗后可再打开查看；不存账号密码。 |

未声明 `cookies`、`webRequest`、`debugger`、`history`、`nativeMessaging`、`<all_urls>`、`tabs` 等权限。虽然不声明 `tabs`，针对被授权 UPW 站点的标签页，扩展仍可通过网站访问权限定位并发送消息。

## 尚待现场验证

1. UPW 页面实际的筛选、日期框及导出弹窗 DOM 是否与源码匹配；界面更新可能需要调整选择器。
2. 同日零交易时先停止，避免静默跳过；成功卡片超过 10,000 条时先停止，因为当前本地导入器只接受一个卡片 CSV。
3. 代理关系段数由使用者指定。本地导入器要求新下载的关系段与历史 UID 出现重叠，不足时会拒绝导入，不能保证只下载一段就足够。
4. 扩展导出后，还需要运行 `../import_exports.py` 先校验，再显式传 `--install` 才会替换本地原始文件；网站更新是后续独立步骤。

## 自动补齐日期（界面选项 1）

扩展不能自行扫描本机 Excel 目录。先在本机运行 `python3 tools/upw-download/coverage.py`，它会按现有 UPW 交易原始文件生成项目目录与桌面操作台 `01-下载数据/upwdownload/` 的两份 `UPW-已导入日期.json`。在页面内面板中首次点击“选择日期清单”，选桌面操作台这一份（从旧弹窗升级后须重新选择一次；Chrome 可能显示本机文件读取授权）。扩展会在每次点“自动补齐”前重新读取该文件，计算从最早交易日期到后台 UTC+8 昨天之间的缺失日期，最多一次导出 90 天；已有日期跳过。面板分别显示最新交易日期和清单生成日期，两者不是同一个概念。手动指定日期是选项 2。

成功运行 `../import_exports.py ... --install` 后，导入器会自动刷新这份日期清单。若有人绕过导入器直接改原始 Excel，需再运行一次 `coverage.py`，否则扩展读取的是旧清单。清单只记录日期，不包含交易明细。这里的“已覆盖”沿用本地流水的日期识别逻辑；早期历史文件并非逐日经过此扩展校验，不能把“文件里出现该日期”当作完整性审计结论。

此次没有新增扩展声明权限；读本机 JSON 由 Chrome 文件选择器单独授权。更新已安装的本地扩展后需在 `chrome://extensions` 点击“重新加载”。尚未在真实 UPW 后台端到端验证。

首次安装需确认上述权限，在原有 Chrome 的 `chrome://extensions` 开发者模式中“加载已解压的扩展程序”。当前桌面操作台已有一份扩展，更新代码后只需重新加载原有扩展；不要重复安装第二份，也不要声称自动下载已完成后台端到端验证。
