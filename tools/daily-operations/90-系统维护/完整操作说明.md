# 操作台维护说明

日常操作请看操作台根目录的 `00-先看这里.md`。本文件供维护程序的人参考；平时不需要打开。

## 当前结构

- `01-测试更新`：从 `03-原始数据` 刷新输入副本，重新计算并同步到独立测试数据库。
- `02-正式发布`：校验测试成功凭据与输出校验值，然后原样发布已验收 CSV 到正式数据库，不重新计算。
- `03-原始数据`：原 Desktop 数据目录的符号链接；没有搬迁原始文件。
- `04-出错时再看`：四个仅核验入口及运行日志。核验操作不会重新计算或上传。
- `90-系统维护`：统一管线、共享同步代码、数据库说明和旧入口。

## 重要区别

操作台“正式发布”只发布测试验收通过的数据，不部署网页或 Apps Script 代码。网站代码变更仍应先部署 staging，由用户验收后再部署同一源码到 production。

公开测试环境会显示真实运营汇总数据；不要发布原始订单/卡片明细或同步密钥。
