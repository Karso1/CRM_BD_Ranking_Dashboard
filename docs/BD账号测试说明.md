# 网站账号与 BD 权限

测试网址：https://upay-bd-ranking-staging.karsol.workers.dev

测试站与正式站使用同一套权限逻辑，但账号配置各自独立。最初正式站账号由测试站已验收的账号复制；以后在各环境的 `账号管理.command` 中单独新增或修改。管理员可看完整数据，BD 只能看绑定 BD 名下的数据。

## 查看账号

双击 `tools/daily-operations/01-测试更新/账号管理.command`，选择 `3. 查看现有账号和权限`。程序会显示本机记录的账号数量、用户名、管理员或 BD 权限，以及 BD 归属；密码默认遮住。若要看明文密码，需再次输入“显示”。不要截图或分享显示密码的窗口。

每次操作结束后，可按 Enter 返回账号菜单继续操作，或输入 `0` 退出。

这里读取的是本机保存的记录，不是 Cloudflare 的账号清单。Cloudflare 无法返回已保存的明文密码；如果曾在 Cloudflare 控制台直接修改账号或密码，本机记录可能不是最新的，应以实际登录测试为准。记录文件仅限本机用户访问，不上传 GitHub。

建议用无痕窗口或另一浏览器测试 Katrina 账号，以免与当前浏览器保存的 UPay 管理员登录状态混淆。先退出当前账号，再输入 Katrina 用户名和密码。

## 自己修改 BD 用户名和密码

打开 `tools/daily-operations/01-测试更新`，双击 `账号管理.command`，选择“修改账号或密码”→“BD”。只有一个 BD 账号时，选择账号可以直接按 Enter；随后输入新用户名（直接按 Enter 保留原用户名），再输入两次新密码。新密码至少 12 位，输入时终端不显示字符。工具会更新测试网站的后台 Secret，保存本机记录，并尝试登录核验；不需要重新运行数据更新程序。

修改后该 BD 的旧登录状态会失效，UPay 管理员及其他 BD 账号不受影响。若工具显示“密码已保存，但暂未确认网站生效”，先稍等并使用本机记录里的新密码尝试登录，不要反复修改。原始的 `BD账号.local.txt` 请妥善保管；修改 BD 账号不等于修改 UPay 管理员账号，后者在同一菜单选择“修改账号或密码”→“UPay 主管理员”。

## Katrina 可以看到什么

Katrina 登录后进入与 UPay 管理员相同布局的看板，保留平台切换、日期筛选、图表、排名、代理详情和浏览器导出。BD 筛选只显示 Katrina；所有金额、目标、趋势、代理及邮箱都来自 Katrina 名下的数据。原有的管理员看板布局不变。

后台从测试站已发布的快照中按原始 `owner=Katrina` 过滤月度、每日、代理资料。可供 BD 账号读取的前端包不再包含完整备用快照；数据接口只返回 Katrina 范围，数据发布接口不可使用。没有发布快照时返回不可用，不会回退为完整数据。

## 新增其他 BD 或管理员（测试站）

在 `tools/daily-operations/01-测试更新` 双击 `账号管理.command`，选择“新增账号”→“BD”。先从屏幕列出的 BD 中输入要绑定的名称，再设置用户名和密码。名称以当前测试站业务数据为准，不能手填一个不存在的 BD。新增后，后台会把该账号标记为 BD，只返回该 BD 名下的 UPB/UPW 数据，不能读取完整数据或发布数据。

若要增加一个与 UPay 主管理员权限相同的账号，在同一菜单选择“新增账号”→“管理员”。新增管理员可以查看完整数据；账号名称本身不会决定权限，新增时选择的账号类型才决定权限。菜单会阻止用户名与已有管理员或 BD 冲突，要求输入两次密码，并在保存后尝试登录核验。新增账号不会改变现有 UPay 管理员或其他 BD 的密码。

账号和密码分别记录在本机的 `BD账号.local.txt` 与 `其他管理员账号.local.txt`，不会上传 GitHub。不要直接编辑这些文件；新增和修改测试站账号统一使用 `账号管理.command`。本机账号记录在 Finder 中隐藏，以免把密码文件误当操作入口；内容和路径没有改变。

## 维护者命令

维护者可运行 `python3 tools/site-access/add_bd_account.py --username <用户名> --owner <BD名称>`，为测试站生成独立密码并更新测试 Worker Secret。用户名和 BD 归属必须与业务表核对。此入口适合增加新账号；修改已有账号请优先使用上面的双击入口。

正式站的操作入口在 `tools/daily-operations/02-正式发布/账号管理.command`。首次同步后，两个网站的账号和密码相同；今后在一个环境中改账号，不会自动修改另一个环境。账号操作不重新计算或发布业务数据。
